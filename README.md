永い後日談のネクロニカ キャラクター作成補助シート
ネクロニカのキャラメイク時、「強化値を見ながらどのマニューバー（パーツ）を装備できるか何度も往復して確認するのが大変……」という悩みを解消するために作成したWEBツールです。

ビルドの構成案やパーツ配置の組み立てをスムーズに行うための「下書き・調整用ツール」としてご活用ください。ここで構成を決めてから、キャラクター保管所等に清書する使い方の想定となっています。

💡 特徴・機能

パーツ配置枠の自動計算 クラスやポジション、レベルに応じた配置上限と現在の装備数をリアルタイムで判定します。
データ内蔵 パーツ・スキル等のデータを選択・参照しながらスムーズに組み上げられます。
データ内蔵 　窮愛点の追加、計算ができます。
保管所貼り付け用テキスト出力 作成したデータをキャラクター保管所のメモ欄等に一括で貼り付けられるテキスト出力機能を搭載しています。
⚠️ ご利用にあたって

データの取り扱いについて 本ツールに含まれるデータは、公式で配布・公開されている範囲の効果を記載しています。 他マニューバの説明はルルブを参照してください。
データ保存について 入力したデータはブラウザ（ローカルストレージ）に保存されます。
